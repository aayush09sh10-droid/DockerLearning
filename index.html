1 Abstract
FormFit AI is a real-time exercise form analysis system that uses a standard webcam to detect human body landmarks and provide live coaching feedback. By combining MediaPipe BlazePose for skeleton tracking with a Random Forest classifier built on scikit-learn, the system evaluates exercise technique across three movements — Bicep Curls, Squats, and Push-ups — classifying each frame as Correct or Incorrect while simultaneously counting repetitions via a noise-resilient state machine. The entire solution runs offline on a standard laptop with no specialized hardware required.
2 Problem Statement & Existing Systems

Many gym-goers perform strength training with incorrect form, reducing muscle activation and increasing injury risk. Access to a personal trainer is expensive and not universally available. FormFit AI provides an accessible, zero-cost software solution using only a webcam.

8 Feature Extraction — landmark_extractor.py

All features are computed from the normalized (x, y) coordinates of MediaPipe landmarks using vector mathematics.

Core Algorithm — calculate_angle(a, b, c)

ba = a − b                           # vector from joint b to point a
bc = c − b                           # vector from joint b to point c
cosθ = dot(ba, bc) / (‖ba‖ × ‖bc‖)  # dot-product formula
θ    = arccos(clip(cosθ, -1, 1))     # interior angle at joint b (degrees)

9 Machine Learning Model

Training Pipeline (train_model.py)

#StepDetail
1Load dataRead CSV, drop NaN rows; bicep curl is comma-separated, others tab-separated
2Encode labelsLabelEncoder maps "correct"/"incorrect" → 0/1, saved as .pkl
3Train/Test SplitStratified 80/20 split with random_state=42
4Train modelRandomForestClassifier(max_depth=5, class_weight='balanced')
5Save modelPersisted via joblib.dump() as {exercise}_classifier.pkl

Why Random Forest?

Handles non-linear interactions between joint angles; class_weight='balanced' corrects for class imbalance; max_depth=5 prevents overfitting on a small dataset. Inference is near-instant, suitable for real-time per-frame prediction.

11 Repetition Counter — exercise_counter.py

The ExerciseCounter implements a two-state machine with moving-average smoothing (window = 5 frames) to suppress MediaPipe jitter.

14 Limitations
  • 💡
    Lighting sensitivity — Poor lighting degrades MediaPipe landmark detection, causing erratic angle outputs.
  • 📊
    Small dataset — Only ~154 samples for bicep curl; a larger dataset would meaningfully improve classifier robustness.
  • 🕐
    Frame-by-frame classification — No temporal context; a single "bad" frame can trigger incorrect feedback. An LSTM-based approach would fix this.
  • 📐
    2D features only — Ignores the Z-axis depth coordinate that MediaPipe provides, which could improve angle accuracy significantly.
  • 💪
    Left-side bias — Bicep curl originally analyzed only the left arm. Push-ups were extended to both arms.
  • ⚙️
    Heuristic thresholds — Feedback rules (e.g., offset > 0.15) are manually tuned and may not generalize across different body types or heights.
  • 🏥
    Not a medical tool — Not validated for clinical injury prevention; should not be used as a substitute for professional assessment.

16 Conclusion & References

Conclusion

FormFit AI is a well-structured, end-to-end working prototype that demonstrates how open-source computer vision and machine learning can be combined to create accessible fitness technology.

  • ✅ Detects and tracks human pose landmarks in real-time via MediaPipe
  • ✅ Extracts meaningful biomechanical features using dot-product vector math
  • ✅ Classifies exercise form with ~77% accuracy using a Random Forest classifier
  • ✅ Counts repetitions reliably via a noise-resilient state machine
  • ✅ Delivers actionable, exercise-specific textual feedback in real-time
  • ✅ Supports 3 distinct exercises from a single unified application
  • ✅ Clean modular architecture with strong separation of concerns
